Leonida Ledger — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a five-step platinum roadmap built from the official descriptions, the one possibly missable trophy flagged, and a checklist saved in the browser with export and import, kind filters and a spoiler setting.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide is plain static files under `app/`, works with the network off, and makes no network requests.
